# 나의 일기장 (PWA)

설치해서 앱처럼 쓰고, 오프라인에서도 동작하는 일기장 웹앱입니다. 빌드 도구나 라이브러리 없이 순수 HTML/CSS/JavaScript로 만들었습니다.

## 기능
- ✍️ 일기 작성 / 수정 / 삭제 (제목, 본문, 날짜, 기분, #태그)
- 😄 기분 이모지 6종
- 🔍 제목·본문·태그 검색 (검색어 강조)
- 📅 달력 보기: 날짜별 기분 표시, 날짜를 눌러 그날 일기만 보기
- 🔥 연속 작성일 표시
- 💾 자동 저장: 뒤로 가기, 앱 전환 시 작성 중인 내용 보존 (Ctrl/⌘+S 저장)
- 🌙 다크 모드 (시스템 / 밝게 / 어둡게)
- 📦 JSON 백업 내보내기 / 불러오기
- 📴 오프라인 지원 (Service Worker), 홈 화면 설치

데이터는 서버 없이 **기기 브라우저의 IndexedDB에만** 저장됩니다. 기기를 바꾸기 전엔 설정 → 백업으로 내보내 두세요.

## 실행
Service Worker는 `https` 또는 `localhost`에서만 동작합니다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 배포 (GitHub Pages 예시)
모든 경로가 상대 경로라 하위 경로에서도 동작합니다. 저장소 Settings → Pages → 브랜치 선택 후 저장하면 됩니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 스타일 (라이트/다크) |
| `app.js` | 앱 로직 |
| `db.js` | IndexedDB 저장소 |
| `sw.js` | 오프라인 캐시 (파일 수정 후 배포 시 `CACHE` 버전 올리기) |
| `manifest.webmanifest`, `icons/` | 설치 정보와 아이콘 |
