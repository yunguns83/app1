# 입금 알림 → 카카오워크 (PWA)

한의원 치료비를 계좌이체한 환자의 **이름과 입금액**을 카카오워크 단체방으로 자동으로 보내는 앱입니다.
통장의 다른 입출금은 걸러내고, **직원이 미리 등록한 환자의 입금만** 보냅니다.

```
 [직원]  PWA 앱에서 "홍길동 / 50,000원" 계좌이체 예정 등록
                       │
 [내 폰] 은행 앱 푸시 "홍길동 입금 50,000 잔액…"
   └ MacroDroid 가 알림 문구를 서버로 전송
                       ▼
 [서버] Cloudflare Worker (무료)
   ① 입금 알림인지 확인 (출금·결제·취소는 저장도 안 하고 버림)
   ② 대기 명단의 이름과 비교
   ③ 일치 → 카카오워크로 "환자: 홍길동 / 금액: 50,000원" 전송
      불일치 → '입금 내역' 탭에 표시 → 직원이 환자를 골라 버튼 한 번으로 전송
```

## 왜 이런 구조인가요?
- **PWA(웹앱)는 다른 앱의 알림을 읽을 수 없습니다** (브라우저 보안 제한). 그래서 안드로이드 자동화 앱 **MacroDroid**가 은행 알림을 읽어 서버로 넘겨줍니다. 앱을 새로 만들 필요 없이 설정만 하면 됩니다.
- **카카오워크 봇은 단체방의 일반 대화를 읽을 수 없습니다.** 그래서 직원은 채팅 대신 이 PWA 앱에서 이름을 등록합니다. 같은 주소를 직원 폰·데스크 PC에서 함께 열 수 있습니다.
- **데이터가 서버에 있어서 폰을 바꿔도 그대로입니다.** 새 폰에서는 MacroDroid 매크로만 다시 넣고 PWA 주소를 열면 끝입니다.

## 원래 아이디어에서 더한 점
| 상황 | 처리 |
|---|---|
| 보호자 등 **다른 이름으로 입금** | 등록할 때 '입금자 이름'을 함께 적으면 그 이름으로도 매칭 |
| 직원이 등록하기 **전에** 입금이 먼저 옴 | 등록하는 순간 최근 24시간 입금을 다시 확인해서 바로 전송 |
| 명단에 없는 입금 | '입금 내역'에 주황색으로 표시 → 환자 선택 후 [보내기], 또는 [환자 아님] |
| **예상 금액과 다르게** 입금 | 메시지에 ⚠️ 경고 한 줄 추가 |
| 같은 알림이 두 번 옴 | 10분 안의 같은 문구는 무시. 기업은행·토스처럼 **다른 앱에서 온 같은 입금**(5분 안, 금액·이름 같음)도 한 번만 처리 |
| 동명이인 / 김민 vs 김민수 | 긴 이름 우선, 같은 이름이면 예상 금액이 맞는 쪽, 그다음 먼저 등록한 순 |
| 은행이 이름을 `홍*동`처럼 가림 | 가운데 글자 가림도 인식 |
| 오래된 대기 | 7일(설정 가능) 지나면 명단에서 자동으로 빠짐 |
| 개인정보 | 출금·결제 알림은 저장하지 않고, 입금 알림의 **잔액은 `***`로 가려서** 저장. 기록은 60일 후 자동 삭제 |

## 설치 방법 (처음 한 번, 약 30분)

### 1. 카카오워크 봇 만들기
1. 카카오워크 **관리자 페이지 → 봇**에서 봇을 만들고 **App Key**를 복사합니다. (회사 관리자 권한 필요)
2. 봇은 기존 단체방에 초대할 수 없고 **봇이 직접 방을 엽니다.** 4단계의 설정 화면에서 직원 이메일을 넣으면 봇이 단체방을 만들어 줍니다.

### 2-A. PC 없이 폰으로만 할 때
1. 폰 브라우저에서 [Cloudflare](https://dash.cloudflare.com) 가입
2. 내 프로필 → **API 토큰** → 토큰 만들기 → **'Cloudflare Workers 편집'** 템플릿 선택 → 권한에 **D1 편집**이 없으면 추가 → 토큰 만들기
3. Claude에게 "토큰 준비됐어"라고 말하면, 토큰 입력 창이 뜹니다 (채팅에 붙여넣지 마세요). Claude가 서버를 올리고 주소를 알려드립니다.
4. 앱 주소로 들어가면 **첫 화면에서 앱 비밀번호를 정하고**, 설정 탭에서 **App Key 입력**과 **휴대폰 연결 주소 복사**를 합니다. (아래 secret 명령은 필요 없음)

### 2-B. 서버 올리기 (PC, Cloudflare 무료)
[Cloudflare](https://dash.cloudflare.com) 가입 후, PC에 [Node.js](https://nodejs.org)를 설치하고 이 폴더에서:

```bash
npm install
npx wrangler login
npx wrangler d1 create deposit-notifier      # 출력된 database_id 를 wrangler.toml 에 붙여넣기
npm run db:init                              # 표 만들기
npm run deploy
# 비밀번호·App Key·휴대폰 토큰은 앱 화면에서 정할 수 있습니다.
# 서버 secret 으로 고정하고 싶다면(선택): npx wrangler secret put APP_PASSWORD / KAKAOWORK_APP_KEY / NOTIFY_TOKEN
```
마지막에 나오는 `https://deposit-notifier.○○○.workers.dev` 가 앱 주소입니다.

### 3. 내 안드로이드 폰에 MacroDroid 설정
Play 스토어에서 **MacroDroid** 설치 → 새 매크로:

- **트리거**: 알림 → *알림 수신* → **i-ONE Bank** 앱 선택 → 텍스트 *포함* `[입금]`
  (기업은행 알림 형식: 제목 `입출금내역 알림`, 내용 `[입금] 50,000원 홍길동 156-*******-01-013 11/11 22:46`)
- **동작**: 인터넷/웹 → *HTTP 요청*
  - 방식: `POST`
  - URL: 앱 **설정 탭 → 휴대폰 연결 주소 → [주소 복사]** 한 것을 붙여넣기
  - 본문(Body) 형식: `text/plain`
  - 본문: `[not_title] [notification]` (알림 제목 + 내용 변수)
- 저장 후 MacroDroid에 **알림 접근 권한**을 허용하고, 설정 → 배터리에서 MacroDroid를 **'제한 없음'**으로 둡니다. (안 하면 몇 시간 뒤 멈출 수 있음)

> 트리거에서 `입금`으로 거르는 건 불필요한 전송을 줄이는 용도이고, 서버에서도 다시 한 번 입금만 골라냅니다.

#### 기업은행 앱 + 토스 앱을 같이 쓸 때
- **권장: 돈이 들어오는 계좌의 앱 하나만** 트리거로 고르세요. 기업은행 계좌라면 *기업은행(i-ONE Bank)* 앱만 고르면 됩니다.
- 두 앱을 다 고르면 같은 입금 알림이 두 번 옵니다. 서버가 **5분 안에 금액과 이름이 같은 알림은 한 번만** 처리하니, 카카오워크 메시지가 두 번 가지는 않습니다.
- 토스 알림을 쓸 때는 트리거 텍스트를 `입금` 하나로만 걸면 `○○님이 50,000원을 보냈어요` 같은 알림이 빠집니다. 토스를 고른다면 트리거에 `보냈어요`도 추가하세요. (보낸 돈 알림 `○○님에게 …보냈어요`는 서버가 무시합니다.)

### 4. PWA 앱 열고 설정
1. 앱 주소를 크롬에서 열고 비밀번호 입력 → 메뉴의 **홈 화면에 추가**(또는 상단 [설치]).
2. **설정 탭**
   - *새 단체방 만들기*에 직원 카카오워크 이메일 입력 → [봇이 단체방 열기]
     (이미 봇이 있는 방이 있으면 [불러오기]에서 선택)
   - [테스트 메시지 보내기]로 확인
   - *알림 문구 시험*에 실제 은행 알림 문구를 붙여넣어 **입금으로 인식되고 금액이 맞는지** 확인하세요. 안 맞으면 그 문구(잔액은 지우고)를 알려주시면 규칙을 고쳐 드립니다.
3. 직원 폰/PC에서도 같은 주소로 들어가 설치합니다.

## 매일 사용법
1. 환자가 "계좌이체할게요" → 직원이 **입금 대기** 탭에 이름(필요하면 금액, 보호자 이름) 등록
2. 입금되면 자동으로 카카오워크 단체방에 메시지:
   ```
   💰 계좌이체 입금 확인
   · 환자: 홍길동
   · 금액: 50,000원
   · 시각: 11/11 10:23
   ```
3. 가끔 **입금 내역** 탭의 주황색(명단에 없음) 항목을 확인

## 폰을 바꿀 때
- 기존 폰 MacroDroid에서 매크로 **내보내기**(파일) → 새 폰 MacroDroid에서 가져오기, 권한·배터리 설정 다시 하기
- PWA는 주소로 접속해 다시 설치 (데이터는 서버에 그대로)
- **아이폰으로 바꾸면** 은행 앱 푸시는 읽을 수 없습니다. 은행의 **문자(SMS) 입출금 알림**을 신청한 뒤 단축어 앱의 *자동화 → 메시지 수신*에서 같은 주소로 `POST` 하면 됩니다.

## 알아둘 점
- 폰이 꺼져 있거나 인터넷이 끊기면 그동안의 알림은 전달되지 않습니다. 이 경우 '입금 내역'에 없으니 은행 앱에서 확인하세요.
- 은행마다 알림 문구가 다릅니다. 설정 탭의 *알림 문구 시험*으로 꼭 확인하세요.

## 개발
```bash
npm test                                   # 알림 문구 해석 테스트
cp .dev.vars.example .dev.vars
npx wrangler d1 execute deposit-notifier --local --file=schema.sql
npm run dev                                # http://localhost:8787
```

| 파일 | 역할 |
|---|---|
| `src/worker.js` | 서버 API (알림 수신, 명단, 카카오워크 전송) |
| `src/parse.js` | 입금 판별, 금액 추출, 이름 매칭 |
| `schema.sql` | 데이터베이스 표 |
| `public/` | PWA 화면 (`sw.js`의 `CACHE` 버전은 화면 수정 시 올리기) |
| `test/` | 테스트 |
