# 카톡 요약 (Kakao Digest)

카카오톡 메시지를 하루 동안 모아 두었다가, 매일 정한 시각에 Claude로 요약해서 **카카오톡 "나에게 보내기"**로 보내 주는 안드로이드 앱입니다.

```
카톡 알림 ──▶ 알림 수집(NotificationListener) ──▶ 폰 안의 SQLite
                                                     │ 매일 23:00 (WorkManager)
                                                     ▼
                          Claude API 요약 ──▶ 카카오 "나에게 보내기" API
```

- 별도 서버가 없습니다. 메시지는 폰 안에만 저장되고, 요약할 때만 Claude API로 전송됩니다.
- 14일이 지난 메시지는 자동으로 지워집니다.

## ⚠️ 알림을 끈 방도 수집하려면 (중요)

카톡에서 **"알림 끔"으로 설정한 방은 알림 자체가 만들어지지 않아서 어떤 앱도 읽을 수 없습니다.** 그래서 아래처럼 바꿔 써야 합니다.

1. **카톡 앱**에서 요약받을 방의 알림을 다시 **켭니다**. 채팅방 → ≡ → 알림 켜기.
2. **카톡 앱** 설정 → 알림 → **"메시지 미리보기"를 켭니다**. 꺼져 있으면 알림 내용이 "새 메시지"로만 와서 수집할 수 없습니다.
3. **안드로이드 설정** → 앱 → 카카오톡 → 알림에서 메시지 알림 채널을 **무음, 팝업 없음, 잠금화면에 표시 안 함, 앱 아이콘 배지 끔**으로 바꿉니다. 앱의 "카카오톡 알림 설정 열기" 버튼으로 바로 갈 수 있습니다.
   → 알림은 생기지만 울리지도 보이지도 않으니 지금처럼 조용하게 쓸 수 있습니다.
4. 알림창이 지저분해지는 게 싫으면, 앱에서 **"수집 후 카톡 알림을 자동 삭제"**를 켜세요. 알림을 계속 보고 싶은 방은 "자동 삭제하지 않을 방"에 적으면 됩니다.

방이 늘어나도 새 방의 알림만 켜 두면 자동으로 수집됩니다. 요약하기 싫은 방은 "요약에서 뺄 방"에 이름을 적으세요. 앱 화면의 "오늘 수집" 목록에 보이는 이름 그대로 적으면 됩니다.

### 알려진 한계
- 알림에 담기는 내용만 수집합니다. 사진·이모티콘은 "사진을 보냈습니다" 같은 텍스트로만 남고, 아주 긴 메시지는 잘릴 수 있습니다.
- 폰이 꺼져 있던 동안 온 메시지나 PC 카톡으로만 확인한 메시지는 알림이 오지 않으면 빠집니다.
- 이 방식은 카카오가 공식 지원하는 기능이 아닙니다. 개인용으로만 쓰세요.

## 1. APK 받기

`kakao-digest/` 를 수정해 푸시하면 GitHub Actions가 APK를 빌드합니다.

1. GitHub 저장소 → **Actions** → **kakao-digest APK** → 최근 실행 → **Artifacts**에서 `kakao-digest-apk`를 내려받습니다(zip 안에 `app-debug.apk`).
2. 폰에 옮겨 설치합니다. "출처를 알 수 없는 앱" 설치를 허용해야 합니다.

## 2. 알림 접근 권한 켜기

앱의 **"알림 접근 권한 설정 열기"** → "카톡 요약"을 켭니다.

> Android 13 이상에서 직접 설치한 앱은 "제한된 설정" 때문에 스위치가 회색으로 막혀 있을 수 있습니다.
> 그럴 땐 설정 → 앱 → 카톡 요약 → 오른쪽 위 ⋮ → **"제한된 설정 허용"**을 누른 뒤 다시 켜세요.

**배터리 최적화 제외**도 눌러 두면 매일 예약 실행이 늦어지지 않습니다. 삼성 폰은 설정 → 배터리 → 백그라운드 사용 한도에서 "절전 예외 앱"에 추가하는 것도 권장합니다.

## 3. Claude API 키

[Claude Console](https://console.anthropic.com/) → API Keys에서 키를 만들어 앱의 "Claude API 키"에 넣습니다.

기본 모델은 `claude-opus-5-5`입니다. 비용을 줄이려면 모델 칸에 `claude-sonnet-5-5`나 `claude-haiku-5-5`를 적으세요. 하루 한 번, 방 10~20개 분량이면 비용은 크지 않습니다.

## 4. 카카오 "나에게 보내기" 설정

1. [Kakao Developers](https://developers.kakao.com/) → 내 애플리케이션 → **애플리케이션 추가**
2. **앱 키** → **REST API 키**를 복사해 앱에 넣습니다.
3. **카카오 로그인** → 활성화 **ON**
4. **카카오 로그인 → Redirect URI**에 `https://localhost/kakao-digest`를 등록합니다. 앱의 Redirect URI 칸과 같아야 합니다.
5. **카카오 로그인 → 동의항목** → **"카카오톡 메시지 전송(talk_message)"**을 "선택 동의"로 설정합니다.
6. (보안 → Client Secret을 켰다면 그 값을 앱의 Client Secret 칸에 넣습니다.)
7. 앱에서 **저장 → "카카오 로그인"** → 카카오계정(이메일/전화번호)으로 로그인 → 메시지 전송에 동의합니다.
   - 로그인 화면의 "카카오톡으로 로그인" 버튼은 앱 안 브라우저에서 동작하지 않습니다. 계정 로그인을 쓰세요.

토큰은 앱이 자동으로 갱신합니다. 리프레시 토큰은 약 2개월간 유효하고 사용할 때마다 연장되므로, 매일 실행되면 다시 로그인할 일은 거의 없습니다.

## 5. 테스트

"지금 요약 보내기"를 누르고 잠시 뒤 카톡의 **"나와의 채팅"**을 확인하세요. 결과는 앱 상단 "마지막 실행"에 표시됩니다.

카톡 텍스트 메시지는 한 번에 200자까지라 요약이 `[카톡요약 11/9 1/4]` 처럼 여러 개로 나뉘어 옵니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `KakaoListenerService.kt` | 카톡 알림에서 방·보낸이·시각·내용을 뽑아 저장 |
| `MessageStore.kt` | SQLite 저장소 (중복 제거) |
| `Summarizer.kt` | Claude API 요약 (프롬프트 수정은 여기서) |
| `KakaoApi.kt` | 카카오 토큰 발급·갱신, 나에게 보내기, 200자 분할 |
| `DigestWorker.kt` | 매일 예약 실행, 재시도 |
| `MainActivity.kt` / `KakaoLoginActivity.kt` | 설정 화면 / 카카오 로그인 |

`app/debug.keystore`는 새 APK를 덮어 설치해도 데이터가 유지되도록 고정해 둔 디버그 서명 키입니다.
